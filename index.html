退休规划的三大误区

退休规划，不是退休前才该做的事。下面这三个误区，几乎每个家庭都踩过——越早避开，退休生活越从容。

误区一：靠政府福利就够养老

很多人以为有 CPP（养老金）和 OAS（老年金）就能安心退休。事实上，这两项加起来通常只能替代退休前收入的 30%–40%，远不足以维持原有的生活水平。

更要注意 OAS 的“回拨”（Clawback）：当你的退休净收入超过约 $90,000，OAS 就会被逐步扣减，收入越高，能拿到的越少。

误区二：RRSP 存得越多越好

RRSP 是“延税”，不是“免税”。供款时能减税，但退休提取时 100% 计为收入，可能把你推到更高税阶，甚至触发 OAS 回拨。

  • 聪明的做法是 RRSP / TFSA / 非注册账户 三者搭配；
  • 让未来的提取在不同税务“口袋”之间灵活调配，整体税负更低。

误区三：退休了就该把钱全放进 GIC / 现金

退休后你可能还要再花 25–30 年，通胀会持续侵蚀购买力。完全保守反而带来“长寿风险”——钱比人先花完。适度的稳健增长，依然必要。

解决方案：两个免税退休金工具

避开误区之后，这两个工具特别适合用来打造退休后的“免税现金流”：

  • TFSA（免税储蓄账户）：账户内投资的增长与取款全程免税；退休后提取不计为应税收入，既不会推高税阶，也不触发 OAS 回拨——是退休现金流里最灵活的“免税口袋”。
  • 分红储蓄保险（参与型分红保险）：保单现金价值长期免税复利增长；退休后可通过保单贷款 / 提取，获得稳定的“免税”补充收入，而不增加应税收入；同时还附带终身寿险保障与财富传承功能，一举多得。

一句话：想退休后“少缴税、多到手”，TFSA 与分红储蓄保险是打造免税退休金的两大利器。

新移民必读：落地加拿大的税务规划

从登陆加拿大那一刻起，你就可能成为“全球征税”的税务居民。落地前后做对几件事，能为未来省下一大笔税。

1. 你是“税务居民”吗？

加拿大对税务居民按全球收入征税——全世界的收入都要申报。判断依据是“居住联系”（住所、配偶子女、经济社会联系），而不只是身份或停留天数。

2. 登陆日的“视同购买”——最容易被忽略的省税点

成为税务居民当天，你的海外资产被“视同按当日公允市值买入”。也就是说，登陆之前的增值，加拿大不征税。

  • 务必保留登陆日各项资产（房产、股票等）的市值证明；
  • 将来出售时以此为成本基准，避免把登陆前的增值也算进来多缴税。

3. 海外资产申报 T1135

海外资产成本合计超过 CAD $100,000，每年须随报税申报 T1135 表。漏报罚款很重，别忽视。

4. 用足免税 / 延税账户

  • TFSA：增长与取款全免税；
  • RRSP：供款减税、延税增长；
  • FHSA：首次购房，减税又免税；
  • RESP：子女教育，政府还有补贴。

5. 第一年就报税

即使第一年没有收入，也建议报税：可激活 GST/HST 退税、子女福利（CCB）等。

为什么要买公司保单？

对企业主来说，“用公司买还是用个人买保险”，是一个常被忽略、却能差出很多税的决定。把人寿保险放进公司，往往是更高效的选择。

1. 用“更便宜”的钱缴保费

公司利润的税率通常低于个人最高税率。用公司的钱缴保费，等于用成本更低的资金买同一份保障；若先把钱分红到个人再买，得先缴一道个人所得税。

2. 保单内免税增长，还不挤占小企业低税率

  • 永久寿险保单内的现金价值免税复利增长；
  • 公司里普通投资的被动收入过高（超过 $50,000/年）会侵蚀小企业低税率额度（SBD）；
  • 而保险内的增长不计入这块，帮你守住公司的低税率。

3. 身故赔付经 CDA 免税传承

公司收到的身故赔付，扣除保单成本基础（ACB）后的部分会进入资本股息账户（CDA），可作为资本股息免税派发给股东或继承人——让公司里“被困住”的财富，以免税方式传给下一代。

4. 它还能解决这些问题

  • 关键人保障：核心股东 / 高管身故，赔付帮公司渡过过渡期；
  • 股东买断协议（Buy-Sell）：合伙人一方身故，用赔付收购其股份，避免家族与公司纠纷；
  • 流动性：用保单现金价值做抵押贷款（如 IFA），保留资金继续投资或经营。

适合谁？

  • 有盈利、且短期用不到全部利润的公司；
  • 希望税务高效地积累与传承财富的股东；
  • 有合伙人、需要安排股权传承的企业。

一句话：公司保单不只是“保障”，更是企业主省税、增值、传承三合一的财务工具。

IFA：高收入高净值家庭的避税利器

IFA（Immediate Financing Arrangement，即时融资安排）在高收入、高净值人群中越来越受欢迎——用一张永久寿险，同时实现保障、免税增长、税务优化与现金流保留。

它是怎么运作的？

  • 购买一份永久型（分红）人寿保险，缴入较大保费；
  • 以保单的现金价值作抵押，向银行贷款，把大部分资金“拿回来”继续投资或投入生意；
  • 保单内的现金价值持续免税复利增长；
  • 若贷款用于赚取收入，贷款利息（有时还有部分保费成本）可能税前抵扣；
  • 身故时，赔付先偿还贷款，剩余部分（公司持有时）通过 CDA 免税传承给家人。

适合谁？

  • 持续高收入、现金流稳定；
  • 名下或公司有可投资的资金需求；
  • 能理解并承受杠杆与利率波动。

要注意什么？

这是杠杆策略，受利率与保单表现影响，必须由专业团队（顾问 + 会计师）共同设计并持续跟踪。

一句话：IFA 不是“避税魔法”，而是把保险、信贷、投资三者结合的高级现金流与税务工具。

加拿大有免费医疗，还需要买重疾险吗？

很多新移民觉得“加拿大看病免费，重疾险没必要”。但公费医疗治的是“病”，补不了“病带来的经济损失”。

公费医疗不覆盖什么？

  • 患病期间无法工作的收入损失；
  • 房贷、车贷、孩子学费等照常要还的开支；
  • 部分自费药物、私立康复 / 护理、海外就医、第二医疗意见；
  • 家人为照顾你而停工的损失。

重疾险补的正是这一块

  • 一旦确诊合同约定的重大疾病（癌症、心梗、中风等），一次性赔付一笔免税现金；
  • 这笔钱用途完全自由——补收入、还贷款、请护工、出国治疗都行；
  • 让你能安心养病，而不是一边治病一边为钱发愁。

一个简单的算法

假设家庭月开支 $8,000，一场大病康复期 2 年，仅生活开支就约 $192,000——这还没算收入中断的部分。

一句话：公费医疗保你“治得起病”，重疾险保你“病得起”。两者不是替代，而是互补。

LCGE 终身资本利得免税额，我能用上吗？

如果你拥有一家公司，将来卖掉股份时，可能有一笔上百万的“终身资本利得免税额”（LCGE）——但前提是你的公司“合格”。

LCGE 是什么？

出售“合格小企业公司股份（QSBC）”或合格农场 / 渔业资产时，每人可享有一笔终身资本利得免税额（2026 年起约 CAD $1.275M）。用好它，卖公司时这部分增值可以完全免税。

怎样才算“合格”？（QSBC 三大测试，简化版）

  • 公司是加拿大控股私人公司（CCPC）；
  • 出售时，90% 以上资产用于在加拿大积极经营业务；
  • 出售前 24 个月内，50% 以上资产持续用于积极经营，且股份由你或关联人持有。

常见“踩雷”点

公司里囤积太多闲置现金 / 投资（被动资产），会让股份“不合格”——往往需要提前做“净化（Purification）”，而这些动作通常要在出售前 2 年就开始布局。

能“倍增”吗？

通过让配偶、子女（或家庭信托）合理持股，多个家庭成员可各自动用一份 LCGE，进一步放大免税额度。

一句话：LCGE 是企业主退出时最大的省税机会之一，但“合格”与“倍增”都需要提前 2 年以上规划。

每天一杯咖啡钱，给家人最大的保障

每天一杯咖啡的钱，可能就足以为家人撑起一张几十万的保障网——这就是定期寿险（Term Life）的魅力。

什么是定期寿险？

在你选定的期限内（如 10、20、30 年），若不幸身故，受益人将获得一笔免税赔偿金。它的特点是：保费低、保额高，专注做“纯保障”。

为什么说“一杯咖啡钱”？

  • 趁年轻、健康投保，保费可以非常低；
  • 举例：30 多岁、健康的投保人，几十万的保额，每天可能只相当于一杯咖啡的花费；
  • 用最少的钱，买到家庭最需要的那份安心。

这笔保障能做什么？

一旦家庭经济支柱不在，赔付金可以：

  • 还清房贷、车贷，保住家庭的房子；
  • 支付孩子的教育和成长费用；
  • 覆盖几年的家庭日常开支，让家人有喘息和重新安排生活的时间。

谁最需要？

  • 上有老下有小、收入是家庭主力；
  • 背着房贷、车贷等长期负债；
  • 预算有限，但想先把“万一”的风险兜住。

还有一个隐藏优势

很多定期寿险可在一定年限内免体检转换为永久寿险——先用低保费锁定保障，将来需要时再升级，不必担心届时健康变化而无法投保。

一句话：定期寿险不是为自己买的，而是为了“万一我不在了，家人还能好好生活”而买的。

给子女买保险，还是 RESP？

“给孩子存钱，是买保险还是开 RESP？”这其实不是非此即彼——两者目标不同，搞清楚再决定，甚至可以兼顾。

RESP：为“上学”而生

  • 政府补贴 CESG：供款的 20%，每年最高 $500，终身最高 $7,200；
  • 账户内投资免税增长；
  • 孩子读大专 / 大学时提取，以孩子较低的税率计税。
  • 局限：主要用于继续教育；若孩子不升学，补贴要退回、增长部分提取还可能被加税；供款终身上限 $50,000。

儿童保险（永久寿险）：为“人生”做准备

  • 趁孩子年幼、健康，用极低保费锁定终身可保性（将来即使生病也有保障）；
  • 保单现金价值免税增长，未来可灵活用作首付、创业、补充教育金；
  • 用途不限于读书，也不受“必须升学”约束。

怎么选？

不必二选一。常见做法是：先用 RESP 拿足政府补贴，再用儿童保险做一份灵活、长期的财富储备，两者互补。

一句话：RESP 管“上学”，保险管“人生”——能兼顾，孩子的底气最足。

多套房投资的税务隐患

华人家庭爱以房产置业、投资，但“多套房”背后藏着不少容易被忽略的税务隐患。往往卖之前才发现，已经晚了。

1. 自住房免税，只有一套

“自住房资本利得豁免（PRE）”每个家庭每年只能指定一套房产享受免税。第二套、第三套出售时，增值部分要缴资本利得税。

2. 出租房：资本利得 + 折旧回收

  • 出售出租房时，增值的一部分要计入应税收入；
  • 若你过去申报过房屋折旧（CCA），出售时还要做“折旧回收（Recapture）”，把之前抵扣的折旧补回来计税。

3. 频繁买卖可能被当成“生意”

  • 短期买卖、装修转手（flipping）可能被 CRA 认定为经营收入，100% 计税，还可能涉及 GST/HST；
  • 自 2023 年起的“反炒房规则”：持有不足 12 个月就出售的住宅，通常直接按营业收入征税（搬迁、离婚等特殊情形可豁免）。

4. 传承时的“视同出售”

人离世时，名下房产被视同按市价处分，多套房可能一次性触发大笔资本利得税，给继承人带来现金压力。

5. 海外房产也要申报

持有成本超过 CAD $100,000 的海外房产，每年需申报 T1135；将来出售同样涉及加拿大税。

几点建议

  • 买入前就规划持有结构（个人 / 公司 / 信托）；
  • 保留装修与持有成本凭证；
  • 合理安排自住房的指定年份；
  • 提前为传承可能产生的税款准备流动性（如人寿保险）。

一句话：多套房的税，往往不在“买”时，而在“卖”和“传”时——提前规划才省心。
